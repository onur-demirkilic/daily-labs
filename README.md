# 🚀 Daily Labs
My central "Monorepo" for all daily technical practice and experiments.

## 🤖 Automation (CI/CD)
This repository uses **GitHub Actions** to automate quality checks:
* **Terraform CI**: Automatically runs `terraform fmt` and `terraform validate` on every push to ensure code quality and syntax correctness.

## 📂 Project Structure
* **.github/workflows**: Contains CI/CD pipeline definitions (YAML).
* **/terraform**: Infrastructure as Code (Azure/GCP).
* **/python-basics**: Automation Scripts.
* **/linux-practice**: Bash scripting and CLI notes.
